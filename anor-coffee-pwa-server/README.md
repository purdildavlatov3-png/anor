# ANOR COFFEE PWA — клиентская карта + MySQL + админ-панель

## Что это
PWA (Progressive Web App) — веб-приложение, которое клиент открывает по QR-ссылке и может добавить на главный экран телефона как иконку. Это не Apple Wallet / Google Wallet и не нативное приложение из магазина.

## Состав
- `index.php` — регистрация клиента и его карта.
- `admin/` — вход сотрудников, сканирование QR камерой, начисление штампа, выдача подарка.
- `api/` — PHP API.
- `schema.sql` — таблицы MySQL.
- `manifest.webmanifest`, `sw.js` — установка PWA и базовое офлайн-кэширование оболочки.
- `install.php` — мастер первичной настройки.
- `privacy.html` — черновик политики, который обязательно нужно заполнить реквизитами оператора.

## Требования хостинга
- PHP 8.1+ (желательно 8.2+).
- MySQL 8.0 или MariaDB 10.5+.
- Расширения PHP: PDO, pdo_mysql, mbstring, JSON.
- HTTPS обязателен для камеры и установки PWA.
- Apache с mod_rewrite не обязателен. Корень домена должен указывать на эту папку.

## Установка на сервер
1. Создайте базу MySQL и пользователя в панели хостинга, выдайте пользователю права на эту базу.
2. Загрузите ВСЕ файлы и папки архива в корневую папку сайта (например `public_html`).
3. Убедитесь, что домен уже работает по HTTPS.
4. Откройте `https://ваш-домен/install.php`.
5. Введите параметры MySQL, HTTPS-адрес сайта и придумайте логин/пароль владельца (не менее 12 символов).
6. После сообщения об успешной установке НЕМЕДЛЕННО удалите `install.php` с сервера.
7. Откройте `https://ваш-домен/admin/` и войдите.
8. Проверьте регистрацию клиента на телефоне и сканирование его QR из админ-панели.

## Как работает клиентский QR
QR в админ-панели считывает ссылку с секретным случайным токеном. В базе хранится только SHA-256 хеш токена. Не публикуйте чужие QR-коды. Если карта утекла, потребуется добавить функцию ротации токена.

## Как клиент добавляет иконку
- Android: браузер может показать предложение установки; иначе меню браузера → «Установить приложение» / «Добавить на главный экран».
- iPhone: открыть ссылку именно в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- Установка PWA требует HTTPS (кроме localhost). Иконка использует `/assets/icon-192.png` и `/assets/icon-512.png`.

## Важные ограничения текущей версии
- Клиентская регистрация и начисление штампов серверные, но SMS/OTP-подтверждения номера пока нет. Уникальность номера проверяется БД.
- В админке предусмотрен один тип роли по умолчанию (owner). Таблица поддерживает manager/cashier, но управление сотрудниками и детальные разрешения ещё не сделаны.
- Не реализованы восстановление доступа, подтверждение телефона, экспорт, удаление клиента, ротация QR, уведомления и полноценный аудит админ-действий.
- Политика персональных данных — только шаблон; до запуска заполнить реквизиты оператора и проверить юридически.
- Камера для сканирования требует HTTPS и разрешения браузера. Сканер QR подключается с CDN, поэтому при отсутствии интернета сканирование может не загрузиться.
- PWA-оболочка кэшируется, но клиентские API-запросы требуют сети.
- На iOS PWA установка не вызывается программно: пользователь проходит через меню Safari.

## Безопасность перед реальной эксплуатацией
- Установите HTTPS, сложный пароль владельца, ограничьте доступ к панели.
- Не оставляйте `install.php` на сервере.
- Делайте резервные копии MySQL.
- Добавьте подтверждение телефона OTP, ограничение частоты запросов и процесс отзыва/ротации QR.
- Проведите тестирование и аудит безопасности.
- Не считайте номер телефона подтверждённым без OTP.
- Уточните применимость 152-ФЗ, требования к локализации и уведомлению Роскомнадзора, согласиям и срокам хранения у профильного специалиста.
